To time a frame, the test draws each frame eight times over for its last 3 seconds, so the device can't keep up with the screen, and divides the gap between screen updates by eight. Where the browser offers it, the graphics chip's own timer is shown as well; it reads high on powerful cards, which slow themselves down when there is little to draw. A phone screen refreshes 60 or 120 times a second, so the frame rate moves in steps (120, 60, 40, 30). A frame drawn in 25 ms or less leaves room for the game.
