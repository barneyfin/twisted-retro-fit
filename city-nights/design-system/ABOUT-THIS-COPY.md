# About this copy

This folder is a copy of the approved City Nights design system, version 13 (31 October 2026): https://claude.ai/artifact/4DhkqfUBGEBm3Qj2DeprsM. The artifact is the spec; this copy is here so Claude Code can read it while building the kit. Version 6 changed the crash pop to the smoke cloud (see `../HANDOVER-crash-pop.md`); version 8 added the street's obstacles, animals, passengers and stop bay (see `../HANDOVER-street-pieces.md`); version 9 widened the roadworks sign to 1.45 m so 道路工程 fits; version 10 added Grunge City Rider's play screen: lives, the tip, the round, the pin, the power-up badges and rings, the bay's ring, the passenger getting in, the receipt slip, the SAFE! sign, the zone change, the touch zones, longer districts and the sound (see `../HANDOVER-play-screen.md`); version 11 draws 保's ring on the road under the taxi; version 12 adds 夜光隧道 Nightglow Tunnel at every district line (see `../HANDOVER-tunnel.md`); version 13 makes the stop bay stand out on a phone (bold paint, a low lit sign at its start, three lit posts) and records Grunge City Rider's side rule for touch, with the touch hint's new line (see `../HANDOVER-bays-and-touch.md`).

- **Don't edit these files.** Change the design system first (in Barney's Claude app project), then refresh this copy from it.
- `README.md` is the rulebook. `words.md` is the word list. `tokens.json` holds every token; `tokens.css` is the same tokens as CSS custom properties, generated from it.
- `components/<Name>/README.md` describes each part; `preview.html` shows it. The previews expect the design system page to load `tokens.css`, the fonts, `components/bundle.css` and `components/bundle.js` for them, and their street pictures are stored in the artifact, so opened from this folder they show unstyled and without backdrops. Open the artifact to see them.
- `components/bundle.css` is the interface written as CSS classes (`.cn-…`). `components/bundle.js` draws the seven-segment digits as HTML, holds the crash pop's three drawings (`CityNights.crashPop`) with the Canvas 2D code that draws them (`drawCrashPop`), draws the street's pieces (`CityNights.street`: obstacles, animals, passengers, the stop bay with its sign and posts, the tunnel's portal face) and the play screen's new parts (`CityNights.hud`). Both files are reference for the kit's own stylesheet and script; the crash pop's, the street pieces' and the play screen's drawing code is meant to be ported unchanged.
- `fonts/` and `assets/Licences/` are the kit's fonts and their SIL Open Font Licences. The two Chinese fonts are cut down to the characters on the word list (123 since version 12); Bangers is for the crash pop's letters and the SAFE! sign's word only.
