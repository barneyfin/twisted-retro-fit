The SIL Open Font License texts for the two fonts in `fonts/`. Every game built with Lantern Box carries these alongside its embedded fonts.

- IM Fell English (Regular) and Alegreya Sans (Regular, Medium, Bold) are Fontsource's Latin cuts (@fontsource/im-fell-english and @fontsource/alegreya-sans, version 5.3.0), used as published. Neither licence reserves a font name.
- The Latin cut covers English, the usual punctuation, £ and €, and ↑ ↓ (Alegreya Sans only); it has no ← or →, so keycaps draw their arrows.
