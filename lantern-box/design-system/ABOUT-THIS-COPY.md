# About this copy

This folder is a copy of the approved Lantern Box design system, version 8: https://claude.ai/artifact/WHorELA7gRgEncv7E7vvEY. Version 1 was approved by Barney on 1 November 2026; version 2 (2 November 2026) adds a camera lift for each place and wider steps between the backdrop layers, which he chose on his Pixel; version 3 (the same day) stands the moor's houses on level ground and sets Dawn's nearer hollow mist to 95%; version 4 (the same day) stands each moor stone circle on a low rise and cuts its arch from rough stones; version 5 (the same day) ends every backdrop building's doors and windows at its layer's ground line; version 6 (made in his Claude app project late that day) replaces the four bosses with graded black card ones (the moor mother in place of the cauldron witch) and grades the monsters' card pieces charcoal to ink (see `../HANDOVER-bosses.md`); version 7 (3 November) lightens the card blacks and strengthens the bosses' glow so both show on a phone (see `../HANDOVER-bosses-7.md`); version 8 (4 November) adds everything designed for Gloam Hallow in step 4b's play-parts rounds 1 to 12: the wanderer's moves, the spells, the loot, the rolling ground, the checkpoints, the monsters' and bosses' attacks, the HUD additions and touch controls, the moments, the screens and the sound, plus the new crows and the Mist's leaves (see `../HANDOVER-play-8.md`). The artifact is the spec; this copy is here so Claude Code can read it while building the kit.

- **Don't edit these files.** Change the design system first (in Barney's Claude app project), then refresh this copy from it.
- `README.md` is the rulebook. `tokens.json` holds every token; `tokens.css` is the same tokens as CSS custom properties, generated from it (the design system page makes it and does not publish it; from version 8 it is generated in the Claude app project with the page's own layout and copied here whole).
- `components/<Name>/README.md` describes each part; `preview.html` shows it. The previews expect the design system page to load `tokens.css`, the fonts, `components/bundle.css` and `components/bundle.js` for them, and the Interface previews' backdrops (stills of the places) are stored in the artifact, so opened from this folder they show unstyled and without backdrops, and the version 8 previews that load `components/play.js` stop with an error. Open the artifact to see them.
- `components/bundle.css` is the Interface written as CSS classes (`.lb-…`): the brass plaque, menus, buttons, toggles, segments, the slider, keycaps, numbers, initials, the high-score table, the HUD, the lancet arch and the rotate notice; from version 8 also the HUD additions (round 9), the moments' plaque line, name plaque and place card (round 10) and the screens (round 11). Most of the kit's stylesheet starts here.
- `components/bundle.js` is the World's drawing code: the Gloam Hallow directions page at round 12 (the signed-off look), with a small door at the end, `LanternBox.world`, that picks the approved settings and names the parts. Version 8 (8.0.0) capitalises the boss names and adds the side-on crows (`crowSide`, `drawCrowFlocks`, `drawCrowsAlone`) and the Mist's leaves (`drawLeaves`, `leafShape`). It draws the mock-up way (every layer redrawn every frame). The kit draws the same shapes the speed test's way (`../speed-test/src/kit.js`); port the drawing code unchanged.
- `components/play.js` (new in version 8, 1.0.0) is the play parts as the step 4b review page drew them, in its load order, running beside `bundle.js` and sharing its top-level names. Its header lists the files it was made from. The `loopX` functions are the review loops: the reference for each moment's timing, not game code. It is the spec for step 4c.
- `fonts/` and `assets/Licences/` are the kit's fonts (Fontsource's Latin cuts of IM Fell English and Alegreya Sans, 5.3.0) and their SIL Open Font Licences. From version 8, `assets/Licences/README.md` also notes the source and licence of Barney's two recorded sounds (Pixabay), which are built into `play.js`.
